# PYCAMP 🐍 Python Temel Seviye

Bu repository, Python programlama diline yeni başlayanlar için hazırlanan kapsamlı ders notları ve uygulamalı problem çözme / sınav setlerini içermektedir. İçerik tamamen **Jupyter Notebook (.ipynb)** formatındadır.

## 📁 Repository İçeriği

### 1. Değişkenler ve Veri Yapıları

- **`temel_seviye_degiskenler.ipynb`**
  - Değişken kavramı ve isimlendirme kuralları
  - Temel veri tipleri (`int`, `float`, `str`)
  - Tip dönüşümleri (casting) ve `type()` kullanımı
  - Gelişmiş veri yapıları (`list`, `tuple`, `dict`, `set`) detaylı anlatımı ve örnekleri
  - Bölüm sonu ödev çözümleri
- **`temel_seviye_uygulamali_sorular.ipynb`**
  - Gerçek hayat senaryolarından oluşan 20 adet uygulamalı kodlama sorusu
  - Liste, sözlük (dictionary), küme (set) ve string manipülasyonları üzerine pratik çözümler

### 2. Döngüler ve Kontrol Yapıları

- **`temel_seviye_donguler_kontrol_yapilari.ipynb`** (konu anlatımı)
  - Değişkenler ve veri yapıları hızlı tekrarı
  - `if` / `elif` / `else`, karşılaştırma ve mantıksal operatörler, `in` kontrolü
  - `for` döngüsü, `range()`, `enumerate()`, sözlük ve string üzerinde dolaşma
  - `while` döngüsü ve iz sürme tabloları
  - `break`, `continue`, `pass`
  - İç içe (nested) yapılar
  - Bölüm sonu ödev çözümleri
- **`temel_seviye_donguler_sorular.ipynb`** (20 uygulamalı soru)
  - Her konu için boş kod hücreli sorular ve "örnek çıktı" kontrolleri
- **`temel_seviye_donguler_cevaplar.ipynb`** (cevap anahtarı)
  - 20 sorunun örnek çözümleri, çalıştırılmış çıktılarıyla birlikte

## 📚 Önerilen Çalışma Sırası

1. Konu anlatımı notebook'unu baştan sona çalıştırarak okuyun.
2. İlgili **sorular** notebook'unu açıp çözümlerinizi kendiniz yazın.
3. Takıldığınızda veya bitirdiğinizde **cevaplar** notebook'u ile karşılaştırın.

## 🚀 Nasıl Çalıştırılır?

Bu projeyi bilgisayarınızda çalıştırmak veya Google Colab üzerinden incelemek için aşağıdaki adımları takip edebilirsiniz:

### 1. Google Colab Üzerinde Çalıştırın (Önerilen)

Herhangi bir kurulum yapmadan doğrudan tarayıcınızda açmak için:

1. [Google Colab](https://colab.research.google.com/) adresine gidin.
2. **Dosya -> Not Defteri Yükle** adımlarını izleyerek `.ipynb` dosyalarınızı yükleyin ve çalıştırın.

### 2. Yerel Bilgisayarınızda (Jupyter / VS Code)

Terminal veya komut satırından repoyu klonlayarak bilgisayarınızda çalıştırabilirsiniz:

```bash
git clone https://github.com/KULLANICI_ADINIZ/python-temel-seviye-degiskenler.git
cd python-temel-seviye-degiskenler
jupyter notebook
```
