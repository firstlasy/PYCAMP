# 🐍 Python Temel Seviye: Değişkenler ve Veri Yapıları

Bu repository, Python programlama diline yeni başlayanlar için hazırlanan kapsamlı bir **ders notu** ve **uygulamalı problem çözme / sınav** setini içermektedir. İçerik tamamen Jupyter Notebook (`.ipynb`) formatındadır.

---

## 📁 Repository İçeriği

1. **`temel_seviye_degiskenler.ipynb`**  
   - Değişken kavramı ve isimlendirme kuralları  
   - Temel veri tipleri (`int`, `float`, `str`)  
   - Tip dönüşümleri (`casting`) ve `type()` kullanımı  
   - Gelişmiş veri yapıları (`list`, `tuple`, `dict`, `set`) detaylı anlatımı ve örnekleri  
   - Bölüm sonu ödev çözümleri  

2. **`temel_seviye_uygulamali_sorular.ipynb`**  
   - Gerçek hayat senaryolarından oluşan **20 adet uygulamalı kodlama sorusu**  
   - Liste, sözlük (dictionary), küme (set) ve string manipülasyonları üzerine pratik çözümler
